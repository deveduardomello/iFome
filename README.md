### iQueFome

Desenvolvimento de sistema de delivery completo com controle de acesso e perfis distintos (restaurante e cliente), aplicando autenticação e autorização com **Spring Security** e **JWT**, além de persistência de dados com **JPA/Hibernate**.

Sistema inspirado no **Ifood**, desenvolvimento dos protótipos de tela em **HTML**, **CSS** e **Javascript**. 

Backend criado em **Java** com **Spring boot** como framewwork para potencializar o desenvolvimento. 

Após a conclusão do Backend, o Frontend foi recriado utilizando um framework chamado **thymeleaf**.
